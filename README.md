# Badami-Store-Data-Analysis
Retail Store Sales Data Analysis Dashboard using Microsoft Excel. This project includes data cleaning, pivot table analysis, interactive dashboard creation, and business insights generation to analyze customer behavior, sales trends, top-performing states, channels, and product categories for 2022.
---
# 🎯 Business Objective

The main objective of this project is to:
- Identify high-value customers
- Understand customer purchase patterns
- Optimize state-wise purchasing performance
- Improve marketing campaigns
- Increase customer lifetime value (CLV)


# ❓ Business Problems

- How do sales and orders vary month-wise?
- Which month recorded the highest sales and orders?
- Who purchased more products — men or women?
- Which age group contributes the highest number of orders?
- What are the different order statuses in 2022?
- Which order status has the highest percentage?
- Which channel contributes maximum sales?
- Which are the top 5 states contributing to sales?

---
